# eye

- 分类：噪声
- 英文标识：noise:eye

## 功能介绍
生成「eye」噪波图案。

## 如何使用
从左侧菜单拖入画布即可生成图案，无需输入图像；在右侧参数面板调节公共参数（尺寸 / 位移 / 缩放 / 明暗 / 反相 / 动画等）与专属参数。

## 输入
无图像输入（噪波自生成）。公共参数（噪波尺寸 / 横向位移 / 纵向位移 / 横向尺寸 / 纵向尺寸 / 整体明暗 / 颜色取反 / Alpha / 动画）由节点面板统一控制。

## 输出
- **out**：图像输出（RGBA）

## 参数
- noiseOnlyBright：默认 0.2
- noiseSharkX：默认 0.2
- noiseSharkY：默认 0.6
- noiseSpeed：默认 1
- noiseColor1：默认 #004c66
- noiseColor2：默认 #337f66
- noiseColor3：默认 #28766d
- noiseColor4：默认 #ffffff
- noiseColor5：默认 #000000
- noiseRemoveCol：默认 false
