# gyroid Noise

- 分类：噪声
- 英文标识：noise:gyroidNoise

## 功能介绍
生成「gyroid Noise」噪波图案。

## 如何使用
从左侧菜单拖入画布即可生成图案，无需输入图像；在右侧参数面板调节公共参数（尺寸 / 位移 / 缩放 / 明暗 / 反相 / 动画等）与专属参数。

## 输入
无图像输入（噪波自生成）。公共参数（噪波尺寸 / 横向位移 / 纵向位移 / 横向尺寸 / 纵向尺寸 / 整体明暗 / 颜色取反 / Alpha / 动画）由节点面板统一控制。

## 输出
- **out**：图像输出（RGBA）

## 参数
- noiseScale：默认 1
- noiseSpeed：默认 0.1
- noiseWarp：默认 6
- noiseBump：默认 0.2
- noiseSpecular：默认 10
- noiseTintStrength：默认 0.3
- noiseHue：默认 5
- noiseRimColor：默认 #ff9494
- noiseRimPower：默认 2
- noiseRemoveCol：默认 false
