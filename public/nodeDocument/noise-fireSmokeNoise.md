# fire Smoke Noise

- 分类：噪声
- 英文标识：noise:fireSmokeNoise

## 功能介绍
生成「fire Smoke Noise」噪波图案。

## 如何使用
从左侧菜单拖入画布即可生成图案，无需输入图像；在右侧参数面板调节公共参数（尺寸 / 位移 / 缩放 / 明暗 / 反相 / 动画等）与专属参数。

## 输入
无图像输入（噪波自生成）。公共参数（噪波尺寸 / 横向位移 / 纵向位移 / 横向尺寸 / 纵向尺寸 / 整体明暗 / 颜色取反 / Alpha / 动画）由节点面板统一控制。

## 输出
- **out**：图像输出（RGBA）

## 参数
- noiseSpeed：默认 0.5
- noiseFireHeight：默认 210
- noiseWarp：默认 0.4
- noiseFalloff：默认 0.4
- noiseFlameDensity：默认 0.3
- noiseFireSoftness：默认 8
- noiseFireBrightness：默认 1.5
- noiseSmokeAmount：默认 0.3
- noiseSparkDensity：默认 30
- noiseSparkSpeed：默认 190
- noiseDetail：默认 2.4
- noiseFlowStrength：默认 1
- noiseSparkColor：默认 #ff4d00
- noiseRemoveCol：默认 false
