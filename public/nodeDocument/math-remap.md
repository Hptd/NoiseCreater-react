# 值域重映射（Remap）

- 分类：数学
- 英文标识：math:remap

## 功能介绍
把输入区间映射到输出区间。

## 如何使用
把图像或数值连到输入端口；未连线的端口使用面板中的常量。

## 输入
- **in**：输入图像；未连线时使用面板常量
- **inMin**：inMin 输入；未连线时使用面板常量
- **inMax**：inMax 输入；未连线时使用面板常量
- **outMin**：outMin 输入；未连线时使用面板常量
- **outMax**：outMax 输入；未连线时使用面板常量

## 输出
- **out**：图像输出（RGBA）

## 参数
- 输入（in）：默认 0
- 输入下限（inMin）：默认 0
- 输入上限（inMax）：默认 1
- 输出下限（outMin）：默认 0
- 输出上限（outMax）：默认 1
