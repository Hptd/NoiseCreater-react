# 虚线滚动

- 分类：噪声
- 英文标识：noise:dashLineNoise

## 功能介绍
生成「虚线滚动」噪波图案。

## 如何使用
从左侧菜单拖入画布即可生成图案，无需输入图像；在右侧参数面板调节公共参数（尺寸 / 位移 / 缩放 / 明暗 / 反相 / 动画等）与专属参数。

## 输入
无图像输入（噪波自生成）。公共参数（噪波尺寸 / 横向位移 / 纵向位移 / 横向尺寸 / 纵向尺寸 / 整体明暗 / 颜色取反 / Alpha / 动画）由节点面板统一控制。

## 输出
- **out**：图像输出（RGBA）

## 参数
- noiseSpeed：默认 0.2
- noiseRowThickness：默认 20
- noiseDashFreq：默认 4
- noiseDashScale：默认 7
- noiseMoveSpeed：默认 5.1
- noiseXOffsetDiv：默认 3
- noiseDashRatio：默认 0.5
- noiseLineWidth：默认 0.15
