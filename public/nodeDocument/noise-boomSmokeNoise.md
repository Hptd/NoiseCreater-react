# 爆炸烟雾

- 分类：噪声
- 英文标识：noise:boomSmokeNoise

## 功能介绍
生成「爆炸烟雾」噪波图案。

## 如何使用
从左侧菜单拖入画布即可生成图案，无需输入图像；在右侧参数面板调节公共参数（尺寸 / 位移 / 缩放 / 明暗 / 反相 / 动画等）与专属参数。

## 输入
无图像输入（噪波自生成）。公共参数（噪波尺寸 / 横向位移 / 纵向位移 / 横向尺寸 / 纵向尺寸 / 整体明暗 / 颜色取反 / Alpha / 动画）由节点面板统一控制。

## 输出
- **out**：图像输出（RGBA）

## 参数
- noiseBoomColor1：默认 #33264d
- noiseBoomColor2：默认 #e6260d
- noiseBoomColor3：默认 #e6801a
- noiseBoomColor4：默认 #f2f259
- noiseSmokeColor1：默认 #33264d
- noiseSmokeColor2：默认 #594d73
- noiseSmokeColor3：默认 #807399
- noiseBgColor：默认 #808080
- noiseCycle：默认 2
- noiseZoom：默认 7
- noiseBoomDistort：默认 0.5
- noiseSmokeDistort：默认 1.5
- noiseBubbleW：默认 0.5
- noiseSmokeBubbleW：默认 0.75
- noiseBorderWidth：默认 0.02
- noiseMixThreshold：默认 1.25
- noiseRemoveCol：默认 false
